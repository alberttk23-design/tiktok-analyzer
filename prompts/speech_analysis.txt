# FINAL SPEECH ANALYSIS OVERRIDE — HIGHEST PRIORITY

1. SPOKEN HOOK
The spoken hook MUST be based ONLY on the transcript content occurring within approximately the first 3 seconds.

Do not use later transcript content to describe the spoken hook.

If no meaningful speech occurs within the first 3 seconds:
spoken_hook.type = "none"
spoken_hook.message = null

2. CLAIM FILTER
spoken_claims must contain only claims that help explain why a viewer may want, trust, value, or understand the product.

Exclude:
- filler
- assembly/setup narration with no selling relevance
- incidental actions
- procedural details
- repeated wording

Examples of low-value details that should normally NOT become claims:
"put a box inside the planter"
"added a blanket"
"used plastic bags"

Keep claims such as:
"fits a tight corner"
"looks realistic"
"requires no watering"
"comes potted"
"costs less than alternative"

3. CTA STRICTNESS
A rhetorical question is NOT a CTA.

Examples that are NOT CTA:
"Could you see this in your home?"
"Do you like it?"
"What do you think?"

CTA requires an explicit requested action such as:
buy, shop, click, follow, comment, check link, visit link, choose size.

4. PERSUASION PRECEDENCE
The fields must be logically consistent.

If an explicit price comparison is a major part of the transcript:
spoken_persuasion = "price_comparison"

If an explicit competitor/store comparison is a major part:
spoken_persuasion = "competitor_comparison"

Do not return "claim_only" when comparison is clearly being used as persuasion.

5. COMPARISON
comparison.present = true ONLY when an explicit comparison exists.

Mentioning a retailer as the purchase location is NOT automatically a comparison.

Example:
"found this at Costco"
→ comparison.present = false

Example:
"Costco sells one for $350 but this costs much less"
→ comparison.present = true
